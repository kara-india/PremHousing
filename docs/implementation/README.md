# Implementation work windows

Use [`MASTER_WORKLIST.md`](MASTER_WORKLIST.md) as the source of truth for task status. Each task window is limited to ten minutes; once one task is complete and verified, update the list, report the result, and wait for the user to review before moving on. The expanded schema proposal is in [`schema-design-v1.md`](schema-design-v1.md) and has not been applied to Supabase.
